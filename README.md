# Movie Review Sentiment Analysis: Word2Vec and Transformers
This project focuses on automated sentiment classification of movie reviews using Natural Language Processing and Machine Learning. A dataset of 10,000 movie reviews with positive and negative sentiment labels was analyzed and represented using two different text embedding techniques: Word2Vec and the pre-trained Sentence Transformer (all-MiniLM-L6-v2). The generated embeddings were evaluated using Random Forest and Neural Network classifiers to compare their classification performance. Among the four combinations, Sentence Transformer with Neural Network achieved the highest test accuracy of 78.72%, followed by Word2Vec with Neural Network at 73.36%, Sentence Transformer with Random Forest at 72.81%, and Word2Vec with Random Forest at 65.35%. The results demonstrate that contextual Transformer embeddings provide a more effective representation of movie reviews than traditional Word2Vec averaging, although the difference between training and testing performance indicates potential overfitting.
